# InterVent-Replit

A smart HR interview platform built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- Modern login & registration UI
- Role-based registration (HR Manager / Student)
- Dark / light mode toggle
- Form validation with Zod + react-hook-form
- Smooth animations with Framer Motion

## Stack
- React 19 + Vite + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Wouter (routing), Framer Motion, Lucide React
